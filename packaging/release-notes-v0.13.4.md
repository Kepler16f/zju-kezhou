# 课舟 ClassArk v0.13.4

本轮集中修复培养方案口径、审计/选课三态、AI 助手与界面空间问题。

## 修复
- **军体类/思政类、美育类/劳育类混类**：全角括号标题（如 `（2）军体类（8学分）`）
  现按独立板块解析；类别判定增加课程名多数派兜底，军体课不再并入思政类、
  劳育课不再并入美育类。
- **审计页/选课页区分已修与在修**：三处页面共用同一套修读状态口径
  （已修=绿、在修=蓝、未修=灰）；在修只作提示，不并入已取得学分。
- **通识选修「多选一」**：识别「多选一 / 任选其一 / 任选一门 / 只选一门」，
  选 1 门即整块达成，模块不再恒红；方案页显示选择提示。
- **个性修读三大板块重复计分**：本专业进阶 / 跨专业学习（微辅修）/ 学生自主修读
  按「并列任选其一」只计一次要求学分，达成度取最优选项，总计不再 20+20+20。
- **「工具」改为成绩页子选项卡**：底栏恢复 4 项（首页 / 方案 / 成绩 / 设置），
  成绩页内分「成绩 / 工具」，并迁移旧版底栏顺序配置。
- **底栏与首页设置占位压缩**：底栏高度与标签收敛，设置页接口卡改为紧凑摘要行。
- **登录诊断日志入口移除**：保留内部排障日志，不再向用户暴露入口。
- **外语应修学分同步**：设置页数值输入真正生效，并同步到方案页外语板块标题、
  三色学分与审计口径。
- **已选外语课同步**：本学期已选外语课进入方案页（蓝色「已选（方案外）」）与
  审计在修口径，不再只存在于选课页。
- **AI 助手**：新消息未读角标；发送失败保留消息，可撤回重发/补发/插队，
  支持停止与取消，迟到响应不污染新消息。
- **AI 推荐课程 JSON 解析报错**：兼容 BOM、SSE 多帧、NDJSON、前后杂质与
  双重编码 JSON；流式接受裸 JSON 行；失败提示附带脱敏响应片段。
