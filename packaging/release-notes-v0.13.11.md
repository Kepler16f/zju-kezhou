# 课舟 ClassArk v0.13.11

紧急热修复：教师模式（选课指导）里「学业达成审计」整块红屏。

## 现象与根因
- **现象**：教师端导入任意合法分享包后，「学业达成审计」区块显示红色渲染异常，任何合法包 100% 复现。
- **根因**：审计引擎 `engine.main()` 成功时返回的是包装对象 `{'report': …, 'report_json': …}`，而审阅页契约要的是**平铺 report**。学生端主线正确取了 `out['report']`，但教师端接线 `onAudit` 把包装 map 原样透传，导致 `ReportSection` 第一行 `report['totals'] as Map` 命中 null 抛 `TypeError`。与脱敏数据无关，是接线形状错配。

## 修复（双保险）
- **修接线**：教师端 `onAudit` 解包后再返回，与学生端契约一致；错误 map（含 `error` 键）原样透传。
- **页面兜底**：审阅页对 `onAudit` 返回值做防御性解包——若拿到的是包装 map（有 `report` 键、无 `totals`）自动展开，杜绝任何调用方再犯同类错配导致红屏。

## 质量
- 新增回归用例：注入 `engine.main` 的包装 map 形状，断言审计区正常渲染（无异常、应修/板块可见）——正是此前逃逸的场景。
- Flutter 690 项测试全绿；Python 引擎 50 项通过；双引擎 parity 一致；只读红线通过；`flutter analyze` 无错误/告警。
