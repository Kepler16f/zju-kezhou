# 课舟 ClassArk v0.13.6

本轮聚焦「课程串匹配」与审计口径：双引擎升级到 **v1.7**，补齐课程变体隔离、已选未获单列、旧缓存自修复与选课卡片字段解析。

## 匹配引擎（双引擎 v1.7）
- **变体课程不再互相误配**：大学英语（I）/（II）/（H）、微积分（甲）Ⅰ/Ⅱ、大学物理（乙）Ⅰ/Ⅱ、上/下、甲/乙/丙/丁 等等级与班型后缀参与判定——只修（或只选）其中一门时，另一门保持「未修」，不再被模糊相似度（≥0.85）串成已修。
- **泛名歧义保护**：成绩单只写「大学英语」而方案同时列 I/II 时判歧义直接放弃，宁缺勿猜；写法变体（Ⅱ ↔ II ↔ 2、全角括号、多余空格）仍能命中同一变体。
- **一处口径，处处生效**：审计匹配、方案页「已修」标记、在修证据降级与选课建议共用同一套变体安全匹配（Dart `engine/matching.dart` ↔ Python `engine/audit.py` 逐字对齐）。
- **真实数据取证**：2026 级食品科学与工程方案 84 门课中 10 门带变体后缀；模拟「只修微积分（甲）Ⅰ」旧逻辑误标 2 门、新逻辑只标 1 门（大学物理（乙）Ⅰ→Ⅱ 同理），已固化为回归用例。

## 审计口径
- **已选未获单列**：`totals` 与各模块新增 `selected_no_credit`，报告卡显示「已选未获 N 门（未计入已取得，也不抵扣缺口）」——在修绝不混入已修，缺口也不被提前抵扣。
- **总学分口径**：毕业总要求以方案声明学分（如 148.5）+ 素质拓展实践（8）为准，模块要求之和另列 `module_required`，两种口径不再互相顶替。
- **三选一与微辅修**：独立「微辅修」板块不计入必修要求；「本专业进阶 / 跨专业学习 / 学生自主修读」并列组保留三个选项并补说明——跨专业学习即修读其他专业的微辅修，任选其一计一次要求学分，不重复计算。
- **认定类板块**：心理健康类与军体类、美育类与劳育类彻底分家，军训不再挂到心理类。

## 旧数据自修复
- 培养方案缓存带**构建版本号**：升级后检测到旧缓存，自动用本机已缓存的官方方案 PDF 重建并按新引擎重算，无需重新上传 PDF。
- 审计报告缓存同理：检测到引擎版本变化即自动重算，避免「装了新版还看旧结论」。

## 选课课程卡片（点按展开）
- **教学班补齐（用户反馈 #2）**：教务课程列表只返回课程级聚合行，教师/时间/地点在「教学班」里。现在点开课程卡会按需拉取该课的教学班（`...JxbList.html`），逐班显示教学班号、教师、上课时间、地点与容量；平行班教师不同，各自匹配评分。只拉用户点开的那一门，失败可再点重试，不批量轰炸教务。
- **字段解析对齐真实教务数据**：课程号（kcdm）、教师、上课时间、上课地点（skdd 优先）逐条解析；`<br>` 分隔的多教师/多时段/多地点清洗为「/」列表，不再原样显示 HTML。
- **教师评分匹配**：按「、，/;｜」拆名逐个查「查老师」评分表（十分制直显），命中显示分数·评价人数·标签，未命中显示「评分：暂无」，全程零联网。
- **评分表扩充**：新增按姓名解析教师 ID 的抓取模式（学院列表反查），已把本学期可查到的教师评分补进本地表；查老师未收录的教师如实显示「暂无」（不编造）。
- **去重**：课程号、学分不再在标题、芯片与详情里重复出现（展开态隐藏重复芯片）。

## 本学期已选：已获学分与已选上分开
- **审计页与成绩页同口径（用户反馈 #1）**：两页共用同一分类函数，把「本学期已选」逐门标成 **已获学分**（成绩单已出分且计学分，已计入上方成绩/GPA）或 **在修（未出成绩）**，并给出「已获 N 门 X 分 / 在修 M 门」的汇总；课号精确优先、课名归一化兜底，变体课（Ⅰ/Ⅱ）不互串。

## 外语新规（2026 级）
- 报告卡展示外语等级核算口径：L1/L2 必修大学英语IV、L3 免修按 0 分核算，并标注「2026级新规 / 旧规」；设置页与方案页同步显示。
