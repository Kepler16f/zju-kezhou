# 课舟 ClassArk 隐私政策

- 生效日期：2026-10-21
- 开发者主体：ClassArk 项目组
- 开源仓库：https://github.com/Kepler16f/zju-kezhou （MIT License）

本政策以条款形式说明我们如何处理信息。

## 一、我们是谁与本政策适用范围

1.1 我们是谁。课舟 ClassArk 由 ClassArk 项目组开发，是运行于 Windows、macOS、Linux、Android、iOS 与鸿蒙的跨平台学业规划助手（Flutter 客户端）。本地优先：我们不运营自建服务器，除本文列明的两类网络通信外，不上传你的任何数据。

1.2 适用范围。学业看板、培养方案审计、选课只读查询、工具、设置、AI 解读（可选）与选课指导模式。

1.3 角色区分。启用 AI 后，你所选模型服务商为独立接收方，按其政策处理请求。

## 二、我们收集哪些信息

### 2.1 你主动提供的信息

2.1 你主动提供的信息。课舟需要你提供两类信息。第一类是教务统一登录（ZJUAM）的账号与密码：我们用它向学校认证与教务系统换取会话，再读取属于你本人的只读数据；密码只写入你设备上的本机沙箱目录并做混淆编码，不会随其它数据外发（登录请求本身会提交给学校认证与教务系统，这是取得数据的必要环节）。第二类是你在设置页填写的自配 AI 服务 API Key：它只写进请求头，用于向你自己指定的模型服务发起请求，同样只存本机。此外还有两类内容由你决定是否产生：AI 助手中的提问文本不持久化保存，随该次请求一并发出；你主动导出的学业档案分享包写入你选择的位置，是否外发完全由你决定。

### 2.2 登录后自动只读拉取的信息

2.2 登录后自动只读拉取的信息。登录成功后，课舟会从教务系统只读拉取五类信息：成绩与绩点，用于学分与绩点看板以及达成度审计；课表，用于时间冲突检测与选课匹配；教务侧的培养方案，用于方案结构化与达成度审计；选课信息（只读查询），用于候选教学班与选课建议卡；以及课堂分（第二/三/四课堂），用于学分看板。这些数据全部只写入本机沙箱，不离开你的设备。

### 2.3 可选输入

2.3 可选输入。你还可以选择提供三类内容：粘贴的脱敏成绩单文本，作为离线数据源使用，只存本机；主动截屏或上传给 AI 的图片，用于生成 AI 解读，不持久缓存，随该次请求发出；以及屏幕 OCR 识别出的文本（仅 Windows 提供），只驻留内存，在你显式同意后随该次问题发出。

### 2.4 我们不会做的教务写操作

选课提交与退课属于教务写操作，本项目中不存在相关代码；仓库 CI 的只读红线扫描会机械检索写接口路径，命中即中断构建。

## 三、我们如何使用信息

3.1 我们仅将信息用于：统一认证与只读取数；本机计算学分、绩点、先修、冲突与缺口；生成报告与脱敏分享包；响应经你确认的 AI 提问；不含敏感值的诊断日志。

3.2 数值全部由本机规则引擎计算，AI 不参与学分等数值计算，只翻译已算好的结果；其输出不构成学业认定依据，正式认定以教务系统为准。

3.3 我们不会将信息用于广告投放、用户画像或无关的模型训练。

## 四、AI 服务与第三方

4.1 启用方式。AI 解读出厂默认关闭，首次点击入口先询问是否开启；同意后默认启用免密钥的公益端点 text.pollinations.ai。你也可改用自配的 OpenAI 兼容、Anthropic、Dify 等端点，或保持关闭。

4.2 发送范围（白名单）。首次发送前弹窗列明范围供你确认。我们仅发送已修课程名、学分、学期与相关成绩，方案要求，选课候选与课表，审计缺口数字及你的问题；不会发送姓名、学号、成绩单明细、教务凭证、会话 Cookie 与方案原文。

4.3 密钥处理。自配 API Key 仅存本机沙箱，仅写入请求头，不入日志、不进异常文案、不回显于界面。

4.4 屏幕识别。仅 Windows 可用，用系统内置 WinRT OCR 本机离线识别，不经云端 OCR；屏幕文字仅经你显式同意后随该次问题发送，不写入对话历史。

4.5 第三方处理。请求发出后由该服务商按其隐私政策处理，我们不二次留存，也无法代其删除。

## 五、信息共享、转让与公开披露

5.1 除你导出的分享包与你发起的 AI 请求外，我们不会共享你的信息。

5.2 分享包（选课指导模式）。你在设置页显式导出，按字段级白名单脱敏：不含分数、绩点、选课凭证号与凭证；默认匿名，实名需显式勾选。导师端为纯审阅态，不登录教务、不发起教务请求。

5.3 我们不会出售或转让你的信息。除单独同意、法定强制要求或为保护合法权益所必需外，我们不会公开披露，并依法告知你。

## 六、信息存储期限与删除

6.1 全部数据仅存于你设备的本机沙箱目录（AI 请求除外）。

6.2 我们仅将数据保留至你删除它为止，不做后台自动上传或跨设备同步。

6.3 设置页"一键清除全部本地数据"删除全部本地数据与凭证（含教务凭证、AI 配置与密钥、偏好与缓存）；卸载应用即全部删除。AI 请求发出后由服务商按其政策处理，本项目不二次留存。

## 七、信息安全措施

7.1 凭证与配置存于沙箱私有目录，混淆编码，权限仅当前用户；移动端由系统沙箱隔离，桌面端为 profile 内私有文件。

7.2 与统一认证、教务系统及 AI 服务的通信均使用 HTTPS。

7.3 登录诊断日志记录卡点与失败原因，不记录密码、凭证与 Cookie 明文。

7.4 教务写接口路径在 CI 中由只读红线扫描机械拦截；规则引擎结论由 Python 与 Dart 双实现对照金标核验。

7.5 我们不做绝对化承诺：本地软件可能存在未发现的漏洞。

## 八、Cookie 与本地存储

8.1 统一认证会话 Cookie 仅驻内存，不写磁盘，进程退出即消失。

8.2 平台本地存储仅保存界面偏好、登录状态、数据源与 AI 配置，位于沙箱目录，随一键清除或卸载删除。

8.3 我们不集成广告、追踪或分析 SDK，不收集通讯录、位置、相机、麦克风；剪贴板仅在你点击"复制/粘贴分享包"时按指令读写一次。

## 九、未成年人保护

9.1 本应用面向在校本科生，含刚入学的大一新生。

9.2 我们不做年龄核验，也不收集与年龄相关的识别信息。

9.3 未成年人使用须在监护人指导下进行，监护人可代为清除与卸载。

9.4 我们仅按本政策处理其信息。

## 十、您的权利

10.1 查阅。应用内可查看本机数据（学业、方案、选课、配置）并导出脱敏分享包。

10.2 更正。粘贴数据与本机缓存可由重新登录或重新粘贴覆盖；分享包实名可重新导出时关闭。

10.3 删除。见第六条，一键清除与卸载即时生效。

10.4 撤回同意。撤回 AI 发送范围同意、关闭 AI 功能、关闭选课指导模式即时生效。

10.5 导出后撤回。分享包导出即脱离本机控制，我们无法收回；你需自行删除本地副本，并可要求指导教师删除副本。

10.6 投诉与建议。通过第十二条联系方式反馈。

## 十一、跨境传输提示

11.1 我们不向境外传输你的个人信息，唯一例外是 AI 请求：发往你自选的模型服务，或未改设置时发往默认公益端点 text.pollinations.ai（位于境外）。

11.2 若要避免跨境传输，请在设置页切换为校内部署或自建的 Dify 实例，或保持 AI 关闭。

## 十二、政策更新与联系方式

12.1 本政策随应用版本更新；处理目的、方式或范围的变更会在应用内提示并同步更新日期。

12.2 联系方式。contact: ClassArk 项目组（浙大校内邮箱，提交前替换为真实邮箱）
