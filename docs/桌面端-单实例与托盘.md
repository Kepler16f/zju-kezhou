# 桌面端：单实例与"关闭收起到托盘"

> 适用版本：0.12.1+13 起。仅 Windows 侧有原生托盘实现；macOS / Linux 目前只有
> "拦截关闭 + 隐藏窗口"这一段，没有托盘图标入口（需要各平台各自的托盘实现）。

## 1. 问题：以前会无限开窗口

旧版 `wWinMain` 每次都无条件 `CreateWindow`：双击几次 `kezhou.exe` 就有几个进程、
几个窗口，各自跑一份 Dart 引擎和登录会话，互相抢凭证缓存与 AI 配置。

## 2. 单实例（`windows/runner/main.cpp`）

1. `CreateMutexW(nullptr, TRUE, L"Local\\KeZhou.Compass.SingleInstance")`
   判定"本用户会话里是否已有实例"；
2. 若 `GetLastError() == ERROR_ALREADY_EXISTS`：
   - `FindWindowW(L"KeZhou.Compass.MainWindow", nullptr)` 找到已有主窗口（隐藏的也能找到）；
     窗口类名已从模板默认的 `FLUTTER_RUNNER_WIN32_WINDOW` 改成课舟专用——那是所有
     Flutter Windows 应用共用的类名，不改会误唤醒别的 Flutter 应用；
   - `PostMessageW(hwnd, kKezhouActivateMessage, 0, 0)` 让已有实例 `ShowAndFocus()`；
   - 第二个进程直接 `return EXIT_SUCCESS`：不建窗口、不装引擎、不读配置。

预期行为：双击第二次不再出现新窗口，只把已有窗口提到前台；即使它正收在托盘里。

## 3. 关闭 → 收起到托盘（两层分工）

| 层 | 做什么 |
|---|---|
| Dart（`window_manager`） | `setPreventClose(true)` 拦 `WM_CLOSE`；`onWindowClose` 里 `windowManager.hide()` |
| C++（`flutter_window.cpp`） | 监听 `WM_SHOWWINDOW`：首次显示后再隐藏就 `Shell_NotifyIcon(NIM_ADD)`；重新显示即 `NIM_DELETE` |

托盘交互：左键单击/双击唤回窗口；右键菜单「显示窗口 / 退出课舟」；资源管理器重启
（`TaskbarCreated` 广播）后自动重挂图标。

## 4. 开关与持久化

设置页「桌面端」分组（**开关只在 Windows 出现**：托盘图标只有 Windows runner 实现；
macOS/Linux 若也拦截关闭，用户关窗后就再也找不回窗口，所以那里一律「关窗即退出」）：

- **关闭窗口时收起到托盘**（默认开）——写入 `<应用支持目录>/compass/ui.cfg`；
- **退出课舟**——`setPreventClose(false)` + `windowManager.destroy()`，与托盘菜单的
  「退出课舟」等价。

`ui.cfg` 与 `ai.cfg` 同一沙箱目录、同一套轻量混淆；**刻意不用 `cache_` 前缀**，
避免"清缓存"顺手把用户习惯清掉。设置页「数据与合规 → 一键清除全部本地数据」
会一并删除它并恢复默认（开启收起到托盘）。

启动顺序：`main()` 里 `windowManager.ensureInitialized()` → 读 `ui.cfg` →
`setPreventClose(值)` → 注册 `_TrayCloseListener` → 之后才 `waitUntilReadyToShow`。
所以开关在窗口出现之前就已生效，不存在"首帧闪一下再关"的竞态。

## 5. 代码位置

- `compass_app/windows/runner/main.cpp` —— 命名互斥量 + 唤醒已有窗口
- `compass_app/windows/runner/flutter_window.{h,cpp}` —— 托盘图标 / 菜单 / `WM_SHOWWINDOW` 状态机
- `compass_app/windows/runner/CMakeLists.txt` —— `shell32.lib`、`/utf-8`
- `compass_app/lib/data/credential_store.dart` —— `saveCloseToTray` / `loadCloseToTray` / `deleteUiPrefs`
- `compass_app/lib/main.dart` —— 启动读档、关闭拦截、设置页回调
- `compass_app/lib/pages/settings_page.dart` —— 「桌面端」分组

## 6. 已知限制与验证

- 本仓库开发环境没有 MSVC/CMake，C++ 改动只做了静态审查；请在装有
  Visual Studio「使用 C++ 的桌面开发」的机器上跑 `flutter build windows --release` 验证。
- 托盘被系统折叠进"隐藏的图标"时，需要用户在任务栏设置里固定一次。
- 进程被任务管理器强杀时，托盘图标可能残留到下次悬停（Windows 通用行为）。
