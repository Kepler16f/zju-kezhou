# 选课模块接入说明（zdbk / 正方 xsxk 只读取数 + 跨轮次匹配 + AI 解读）

> 目标：在 App 内**只读**读取 zdbk 选课界面（学生选课，`gnmkdm=N253512`）的入口与课程列表，
> 按"课程+教学班"身份跨轮次对齐，与培养方案/审计/课表做确定性匹配，并以**可选**的 AI 解读
> 把建议卡翻译成文字。
> 代码位置：`lib/data/xk_parse.dart`（解析）、`lib/data/xk_models.dart`（身份与合并）、
> `lib/data/zju_client.dart`（取数）、`lib/engine/selection.dart`（确定性分析）、
> `lib/data/ai_prompts.dart`（AI 边界与载荷）、`lib/pages/course_select_page.dart`（页面）。
>
> **红线**：只读查询；提交（`xkBcZyZzxkYzb`）、退课（`tuikBcZzxkYzb`）、批次刷新（`xkBcZypx`）、
> 写链路前置探针（`cxXkTitleMsg`）**绝不调用**，且 `eval/check_readonly.py` 在 CI 做机械拦截。

## 2. 轮次语义与"不用轮次"的实现

- 轮次/类别为**页面内嵌**（`onclick="queryCourse(this,'<参数1>','<参数2>',...)`），无独立轮次列表接口；
- 解析只锚定 `queryCourse(`、`this` 与**前两个字符串参数**（公开实例存在 4/5 参两种形态，
  第 4/5 参含义无证据）；默认入口取 onclick 首条；`xklc` 无证据来源 → 置空显示"轮次未标注"，**不臆取**；
- **"自动识别当前轮次"的操作化定义**：= 服务端在当前页面列出的选课入口（UI 文案写"当前页面可用的
  选课入口，状态以实时拉取结果为准"，不做"正在进行"的强断言）；
- **跨轮次汇总**：对每个列出的入口逐一拉取（显式按钮触发、串行、间隔 ≥1.1s、可取消；
  单轮则点选即拉），按 §3 身份规则合并，容量/已选以快照序列展示（`60/45 → 60/52`）。

## 3. 身份三档降级链（跨轮次匹配核心）

列表层字段名跨实例不一致（有的实例无 `jxb_id`/无 `sksj`），身份按档位降级：

| 档 | 条件 | 身份键 | 语义 |
|---|---|---|---|
| 1 | 有 `jxb_id` | `kch_id(或 kch) + jxb_id + 归一化课程名` | 教学班主键；含课程名是为把"同 jxb_id 不同课程名"的数据异常拆开（不静默合并） |
| 2 | 无 `jxb_id`，有教师+时间 | `kch + 归一化(教师|时间)` 指纹 | 仅展示合并 |
| 3 | 两者皆无 | 仅课程 | 合并并标注"**无法区分平行班**" |

- **"同一教学班跨轮稳定"是工作假设（待 LIVE 校准）**：合并只用于只读展示、不参与任何判定；
- 同名同教师同时间但 `jxb_id` 不同 → 双方标"疑似同一教学班（轮次间标识变化）"，**不自动合并**；
- `do_jxb_id`（约 256 位加密串，每轮动态）只属于写链路，不进缓存与身份键、不出现在本模块任何代码路径；
- 容量/已选多键尝试：`jxbrl|capacity`、`yxzrs|selected_number|yxrs`；全缺显示「未知」而不是 0。

## 4. 空数据三态（评审A6，UI 文案三分）

| 状态 | 判定 | 可否缓存 | UI 文案 |
|---|---|---|---|
| `data` | 列表非空 | 可（带 `fetched_at`） | 该入口共 N 条课程（只读查询快照） |
| `empty` | 接口明确返回空数组 | 可 | 该入口已开放，当前查询结果为空 |
| `unavailable` | 无信封/非 JSON/`usable:false`/验证码/全部行字段缺失 | **不可**，仅留痕 | 状态未知（未开放/会话受限/接口未返回），**不代表没有课程** |

## 5. 上课时间解析（`parseSksj`，全仓此前无先例）

- 输入变体：`星期一/周X/礼拜X`、`第3-4节/第3,4节/第3、4节/第3~4节/第3—4节/第9节`、全角、
  多段（多段以星期标记切分，不在逗号上切以免切坏节次）、`{1-16周}`/`(1-15周(单))`/`{1-8,10-16周}`；
- 输出 schema 对齐 `Timeline.slotsConflict` 消费：`{day:1..7, start, end, week_start, week_end}` 全 int；
- **单双周逐周展开**（`week_start=week_end=w` 枚举奇/偶周），避免与相反奇偶周课程产生假冲突；
- 缺周次 → 按 1-16 周（与 `slotsConflict` 缺省一致）并 quality 留痕；
- 解析不出 → `[]` + 留痕（冲突"未检查"，绝不渲染成"无冲突"）；
- 课表 `kbList`（`xqj/jcs/zcd`）复用同一解析器（合成 `星期X第a-b节{…周}` 文本），避免第二套周次语义。

## 6. 确定性匹配与建议卡（`engine/selection.dart`）

- 与 audit **同一套匹配算法**（`engine/matching.dart`：course_id 精确 → 名称相似度 0.85，difflib 移植）；
- **offerered 缺失 = 未知**：runtime 方案（教务实时方案）常态是 `offered: null` —— 建议卡输出
  "开课季未标注"，**绝不回显 audit 报告对未知的关闭/红色语义**（那是本功能的独立口径；audit 的
  强转债 `(c['offered'] as List)` 因双引擎 parity 红线本轮不修，见 `docs/开发方案.md` 有记录）；
- 每门候选输出：`role(gap/passed/extra)`、匹配置信度（exact/fuzzy/none）、开课季匹配（yes/no/unknown）、
  先修是否未完成、与当前课表冲突（交集区间文本）、逐条 notes；
- **课表未知时**：notes 明示"未做时间冲突检查（不代表没有冲突）"，冲突计数不虚报；
- 输出独立 JSON（`adviceToPromptJson` 仅供 AI 载荷），**不并入 audit.build() 输出**（双引擎 parity 只锁 build）。

## 7. AI 解读（可选，默认关闭）

- 系统提示词与边界文案唯一来源：`lib/data/ai_prompts.dart`；
- 发送白名单（仅此 7 类）：课程名、学分、性质、缺口数字、候选教学班信息（名/师/时/量/轮次）、
  本学期课表课程名与时段、用户问题；**绝不发送**：学号/姓名/身份标识、成绩明细与成绩单原文、
  密码/票据/Cookie、诊断日志内容、方案 PDF 原文、专业名与年级、其他服务商密钥；
  实现注意：审计报告 warnings **按类型白名单过滤**（`kForwardableWarningTypes`）——
  `failed_recheck` 文案内嵌不及格分数，曾实测把「成绩 55」带进载荷（critical 事故已修，
  `test/ai_compliance_test.dart` 有回归）；输出侧另有 `sanitizeAiOutput` 第二道防线；
- 三 provider：OpenAI 兼容（`/chat/completions`，DeepSeek 预设）/ Anthropic（`/v1/messages`，
  `claude-opus-5-5` 预设；**不携带采样参数**，自适应思考计入 `max_tokens` 故默认 8192）/ Dify（`/chat-messages`）；
  注：Dify 无独立 system 通道，实现把系统提示拼进 `query`（以 `\n\n---\n\n` 分隔，`response_mode: blocking`，单测钉死该行为）；
  地址必须含 `http(s)://` 前缀（漏写会在入口直接判为未配置，避免发送期异常）；
- 工程纪律：TLS 默认校验（**绝不** badCertificateCallback）、后台 isolate 顶层函数、独立链路
  （不复用 zdbk 的 RequestThrottle）、只重试 5xx/超时、apiKey 只进请求头且错误文案洗掉回显；
- **首次发送前**弹出发送范围确认；越界提问（帮排/替选/概率类关键词）在输入侧直接回退固定文案；
- 输出页脚 `kAiFooter` 与页脚免责声明 `kDisclaimer` 由 UI 硬拼接（复制按钮同附）。

## 8. 缓存、合规与清除

- 缓存键：`xk_index`、`xk_<学期>_<xkkzId>`、`timetable_slots`——全部 `cache_` 前缀文件，被
  "一键清除全部本地数据"自动覆盖；AI 配置 `ai.cfg` **刻意不用 cache_ 前缀**（防误删），
  由 `_clearData` 显式 `deleteAiConfig()`；
- 日志只记 路径/状态码/条数/耗时/入口 id——**不记完整 URL（含 su）与响应正文**；
- 探针落盘样本仅课程行（无 su/无 URL），用于字段名校准。

## 10. 其他工程结论（评审沉淀，勿回退）

- **UI 文案限 GB2312**：内置字体为 GB2312+应用文案子集，新增文案不得含 GB2312 外汉字/新 emoji
  （现有 ✅/⚠️/🔴🟡🟢 依赖系统字体回退，属既有豁免）；确需时用 fonttools 重裁两个字重并更新
  `subset_chars.txt`（仓库暂无再裁剪脚本）。
- **页签接线**：`main.dart` 全部跳转使用 `tabScholar/tabAudit/tabSelect/tabSettings` 常量；
  IndexedStack 与 NavigationBar 必须成对增删（选课 = index 4，设置 = 5）。
- **resize 门禁结论**：AI 请求必须后台 isolate（`ai_client.dart` 顶层函数），ExcludeSemantics
  保持全局开启——满足这两条时无需把 AI 链路接入 `_waitForStableWindow`；违反任一则需接入
  （见 `docs/已知问题-Windows窗口resize崩溃.md` 附录）。
- **演示数据**：`assets/samples/xk_demo_candidates.json`（与 `data/samples/` 双侧同步），
  页面提供"加载演示数据（合成样例）"离线入口；演示录制不现场拉 xk 接口。
- 引擎重构记录：`_match/_isPassed` 抽至 `engine/matching.dart`、免责声明抽至
  `engine/disclaimer.dart`，均经"快照逐字节 diff + golden 逐字节 diff + 双引擎 parity"零漂移验证。
