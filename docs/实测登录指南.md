# 校园网实测登录指南（CompassSetup-0.9.3 / app-arm64-v8a-release.apk）

> 这台开发机不在校园网，真实登录只能由你实测。新版已按 Helechron 实战行为重写传输层；
> 若仍有问题，App 右上角"🐞 登录诊断日志"能看到卡在哪一步——截图或"复制"发我即可精准定位。

## 测试步骤

1. 安装并打开（Windows：`Downloads\CompassSetup-0.9.3-win-arm64.exe`；安卓：`app-arm64-v8a-release.apk`，arm64 手机选这个）
2. 顶部切到 **"教务网"**，输入学号 + 统一身份认证密码（与登录 zjuam.zju.edu.cn 相同）
3. 点"登录教务网并审计"
4. 成功：30 秒内出现三色报告，"数据来源"显示 `教务网 zdbk 只读拉取（N 条，会话仅内存）`，且学期/年级自动回填
5. 失败：点右上角 **🐞 图标 → 复制并关闭**，把日志发我

## 本次修复了什么（对照上一版"登不上"）

| 问题 | 上一版 | 本版（对齐 Helechron 实战） |
|---|---|---|
| 校园 portal 自签名证书 → TLS 握手直接失败 | ❌ 没处理 | ✅ `badCertificateCallback` 容忍 |
| 系统代理/TUN/Fake-IP 劫持校内请求 | ❌ 走系统代理 | ✅ `*.zju.edu.cn` 强制 DIRECT |
| Set-Cookie 解析 | 手写正则，易漏 | ✅ `dart:io HttpClient` 原生 Cookie 对象 |
| 成绩接口参数 | 提交体带 queryModel | ✅ 参数全在 URL query、提交体为空 |
| 学期字段 | 猜 `xnxq`（正方没有） | ✅ 从选课课号 `xkkh` 切"20232024-1"段 |
| 票据过期 | 报"请重新登录" | ✅ 内存凭证自动重登（2 分钟票据 TTL） |
| 网络抖动 | 失败即报错 | ✅ 3 次退避重试 + 12s 建连 + 15s 空闲超时 |
| 可诊断性 | 无 | ✅ 每步埋点日志（不含密码/票据值） |

## 若仍失败，日志里重点看哪行

- `网络连接失败 / TLS 握手失败 / 请求超时` → 传输层/网络：先确认连着校园网 WiFi（portal 认证过）；手机关 VPN
- `登录页：execution 不存在` → 拿到的是 portal 拦截页：浏览器先访问 zjuam.zju.edu.cn 完成 portal 再试
- `登录提交：回跳登录页` → 大概率学号/密码错（与网页登录同一套凭证；注意不是教务密码以外的账号）
- `教务网会话：未回跳` → SSO 票据被拒：点合规页"一键清除"后重登
- `成绩解析后为空` → 字段名变更：把日志发我，我改解析器（解析逻辑独立在 zju_parse.dart，9 项单测守护）
