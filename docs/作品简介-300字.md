# 作品简介（295 字，上限 300）

课舟 ClassArk——面向浙大学子的学业规划助手，一套代码覆盖 Windows/macOS/Linux/Android/iOS/鸿蒙，交付即安装包。用学生本人账号只读对接教务系统，实时拉取成绩、课表、培养方案与选课信息：自动结构化几十页方案，逐条审计学分缺口、先修断链、时间冲突并溯源到方案页码；内置 GPA 看板、学期走势、GPA 模拟器与选课跨轮汇总。AI 只做「读和说」：把确定性引擎算好的结果翻译成沟通材料，公益端点开箱即用，发送范围经确认且不含姓名、学号与凭证。另有导师审阅模式：学生自愿导出脱敏分享包，教师端零登录零抓取。数据只读、凭证仅存本机沙箱、结论可溯源，实用且合规。
