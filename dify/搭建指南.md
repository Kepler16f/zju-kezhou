# Dify（aihub）搭建指南 · 逐节点

> 前提：10/12 晚已确认 aihub 可建应用、Code 节点支持 Python3。本指南按"主应用 → M1 工作流 → 知识库"顺序搭建，每个节点给出输入/输出变量与要粘贴的文件。

## 一、主应用「学业罗盘」（Chatflow）

### 变量（开始节点）
| 变量 | 类型 | 说明 |
|---|---|---|
| action | 下拉 select | `audit` / `policy` |
| record_text | paragraph | 粘贴的成绩记录（≤8000 字符；超限在 Code① 里报错引导上传） |
| student_alias / student_major / student_grade / student_current | text-select | 下拉：major=`computer_science|software_engineering`；current=`2026-A|2026-B|2027-A` |
| query | string | 用户问题（policy 分支用） |

### 节点链
```
开始 → 条件分支(action)
├─ audit 分支:
│   Code① 三源适配  ← 粘贴 engine/adapters.py 全文（main 签名已匹配）
│      输入: record_text, student_json={{拼接四个 student 字段的 JSON}}
│      输出: record_json, error(可空)
│   条件: Code①.error 非空 → 直接回复 error 文案（"解析失败，请按格式重贴"）
│   Code② 规则引擎  ← 粘贴 dify/audit_code_node.py 全文（build_embed.py 生成，含 golden）
│      输入: record_json, action="audit" ｜ 输出: report_json
│   LLM 包装  ← 系统提示词 = prompts/m2_narrate.md；上下文 = {{Code②.report_json}} + {{Code①.record_json 中的 parse_warnings}}
│   直接回复
└─ policy 分支:
    知识检索（数据集=学业政策库, Top-k=4, 混合检索+Rerank, 开启引用归属）→ {{chunks}}
    Code③ 相关性打分 ← 粘贴 dify/policy_gate_code.py
       输入: chunks, query ｜ 输出: pass(bool), score
    条件: pass=false → 直接回复【拒答模板】（下方文案，不经 LLM）
    LLM 政策回答 ← 系统提示词 = prompts/m4_answer.md；上下文 = {{chunks}} + 引用来源
    直接回复
```

### 拒答固定文案（条件节点直出）
> 该问题超出我掌握的三份政策文件（学籍管理/交换项目/推免办法）范围，为避免误导不作回答。
> 请查阅：本科生院官网 / 所在学院教务科；涉及学籍异动请联系学院教务科。

### 发布
- 功能：WebApp，开启文件上传（policy 不需要，audit 的导出表先走粘贴，上传能力 P1 再开）
- 链接手机验证 = 10/12 晚硬验收
- **每次 golden 或 engine 更新：重跑 `python engine/build_embed.py`，重新粘贴 Code② 内容**

## 二、M1 工作流「罗盘·方案结构化」

```
开始（文件=培养方案PDF；text=专业名、总学分声明）
→ 文档提取器 → Code 切块（按章节标题分段，注入 [PAGE:n] 锚点；每块≤3000字）
→ 迭代（每块）: LLM 抽取（prompts/m1_extract.md，JSON模式）→ Code 校验（粘贴 dify/m1_validate_code.py）
→ Code 合并（按 course_id/name 去重，模块求和对照总学分声明）
→ 输出：plan.json 文本 + 校验报告 + 人工订正清单
```
产物存 `data/golden/raw_<major>.json` → 人工订正 → `data/golden/<major>.json` → `check_golden.py` → `build_embed.py`。

## 三、知识库「学业政策库」
- 3 份文件：学籍管理、交换项目、推免办法（PDF/Word）
- 分段：高质量 + 父子分段；检索：混合 + Rerank；召回阈值 0.5（10/16 按评测微调）
- 验收：问 10 个库内问题全部带【文档·页码】；问 3 个库外问题（如转专业绩点体育算不算）全部走拒答
